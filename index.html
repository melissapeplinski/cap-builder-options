Classroom Assessment · Prototype options

Assessment Builder: three options to compare

Same content, item analysis, Cognia items, learner supports and results in all three. They differ in how much the teacher has to do and how many pages the flow takes.

Option A

Current CAP flow

6 pages · Setup → Questions → Review → Details → Assign → Final review
  • Matches the CAP prototype page for page
  • Every setting visible in the editor: type, standard, DOK, points
  • Teacher names each misconception, with suggestions
  • Teacher turns on each learner support
  • All analysis checks listed
Most control, most clicks. Easiest to drop into the existing CAP prototype.
Open Option A
Option B

Simplified editor

6 pages · same CAP flow as A
  • Settings collapse into one line; DOK and points fill in automatically
  • Learning components applied automatically, shown as chips
  • Detected misconceptions fill in; other labels are optional
  • Analysis shows issues first, passed checks collapsed
  • Learner supports ready automatically; teachers edit only what they want
Same pages as CAP, much less to fill in per question.
Open Option B
Option C

Three-page flow

3 pages · Create → Review → Assign
  • Everything in Option B
  • Title and standard pick at the top of Create (no Setup page)
  • Assessment settings in a collapsed panel on Review (no Details page)
  • Versions summary on Assign (no Final review page)
  • All learner supports in one place, on Assign
Fastest for just-in-time checks. Departs from the CAP page structure.
